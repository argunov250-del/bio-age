# lib/perf — нагрузка, восстановление, сон (приближение)

Независимая приближённая модель по общедоступным описаниям подобных браслетов. Это не алгоритм
какого-либо производителя и не его копия; не медицинские показатели. Чистый JS (без react-native),
детерминирован: время берётся только из параметра `now`. Импорт: `lib/perf/index` (имя `lib/perf`
занято файлом `lib/perf.js` — лёгкий режим).

`computePerf(ds, result, profile, now)` → `{ strain, recovery, recoveryNull, sleep, strainTarget, healthMonitor, stress, weekly, meta }`.
Все числа конечные или `null`. Нет данных — `null`, а не выдуманное значение.

## Нагрузка (strain, 0–21)
`strain = 21 · (1 − exp(−0.0045 · load))`, load — TRIMP по Эдвардсу (минуты в зоне × номер зоны 1–5,
зоны от % HRmax, HRmax = 208 − 0.7·возраст) — уже считается в `lib/metrics.js`. Чем выше, тем труднее прирост.

| Пример | load | strain |
|---|---|---|
| 30 мин, зона 2 | 60 | 4.7 |
| 60 мин, зона 3 | 180 | 11.6 |
| 90 мин зона 4 + 60 мин зона 3 | 540 | 19.2 |

Уровни: <10 light, 10–13.9 moderate, 14–17.9 high, ≥18 allout. Зоны тренировки (`zones`, 5 чисел) — оценка:
в данных есть только активные минуты и load, поэтому минуты раскладываются по зонам так, чтобы средний номер
зоны совпал с load / минуты (для дня — ещё с учётом z13/z45).

## Восстановление (0–100)
Ночные значения против личной нормы за 30 предыдущих дней (нужно ≥4 ночей). Оценки частей:
HRV: `70 + 2·откл%`, пульс покоя (ночной пульс, иначе покой): `70 − 8·откл bpm`, дыхание: `70 − 5·откл%`,
сон: производительность сна. Веса 0.5 / 0.25 / 0.1 / 0.15, нормируются по имеющимся. Нужен HRV или пульс покоя.
SpO2 и температура — только в `drivers` (в оценку не входят). Зоны: red 0–33, yellow 34–66, green 67–100.
Нет данных → `recovery: null`, причина в `recoveryNull.reason` (`no_sleep`, `no_signals`, `baseline_short`).

## Сон
- Базовая потребность: 8 ч (18–64), 9 (<18), 7.5 (65+); при ≥7 ночей — среднее с личной медианой (6–9.5 ч).
- `needH = база + добавка нагрузки (0.06 ч за единицу strain выше 6, до 1 ч) + добавка долга (25% долга, до 1.5 ч)`.
  Дневной сон не учитывается (в данных нет) — вычитание = 0.
- Долг: недосып относительно базы за 7 ночей с весами 1…0.2, ×0.5, максимум 6 ч. Ночи без данных долгом не считаются.
- Производительность = факт / потребность, максимум 100%. Эффективность = сон / (сон + бодрствование) по стадиям, иначе сон / окно ночи.
- Регулярность: 100 − (среднее абс. отклонение отбоя и подъёма за 4 ночи, мин)/180·100; нужно ≥3 ночей.
- `tonight`: подъём из `profile.sleepPlan.wake`, иначе медиана подъёма за 7 ночей; отбой = подъём − (потребность·цель)/эффективность, цели 100/85/70%.

## Целевая нагрузка
`low = 4 + 0.12·recovery`, `high = low + 4`. Метка: restore / maintain / push. `remaining = max(0, high − текущий strain)`.
Подсказки: `no_recovery`, `keep_easy`, `moderate_session`, `room_to_push`, `in_range`, `over_target_recover`.

## Монитор, стресс, неделя
- Монитор: среднее ± 1.5·SD за 30 дней (пол SD: пульс 2, HRV 8%, дыхание 0.5, SpO2 0.8, темп. 0.3); меньше 4 точек — `nodata`.
- Стресс 0–3: средний дневной пульс вне тренировок и сна над покоем `((пульс−покой)/покой − 0.12)/0.3·3`, ±поправка HRV. Нужно ≥60 минут пульса; иначе `null`.
- Неделя: средние за 7 дней, лучший день по восстановлению, тренд (7 против предыдущих 7, порог 3 п.п.).

## Ограничения
Пульс — часовые/минутные данные телефона или часов, не нагрудный ремень: меньше точность на интервалах и на HRV
(RMSSD из источников разной природы). Zones тренировок приближённые. Потребность сна и веса — эвристики, не
калиброваны на выборке. Стресс — грубая оценка по пульсу.

## Источники идей
Только публичные описания: TRIMP (Эдвардс), логарифмическая шкала нагрузки, HRV/пульс покоя против личной нормы,
потребность сна = база + нагрузка + долг, зоны восстановления светофором.
