# Хирон бесплатно: обучение и сервер

Ноль рублей на обычном пути. Платный GPU и vLLM — только в конце, их можно не читать. Аккаунты и токены этот репозиторий не создаёт и не хранит.

Приложение без адреса сервера отвечает каталогом и в сеть не ходит.

## Какую модель выбрать

Оценки llama.cpp на CPU, не замер этого репозитория. Короткий ответ — около 80 токенов. Промпт добавляет ещё несколько секунд.

| Где | Qwen3-4B Q4_K_M | Qwen3-1.7B Q4_K_M |
| --- | --- | --- |
| Oracle Always Free, 4 ядра ARM | 5–10 ток/с, ответ 10–20 с | 12–22 ток/с, ответ 4–8 с |
| Hugging Face Space, бесплатные 2 vCPU | 2–5 ток/с плюс холодный старт 20–60 с | 6–12 ток/с плюс тот же старт |

**Рекомендация: учить и отдавать Qwen3-1.7B с виртуальной машины Oracle.** Короткий ответ укладывается в несколько секунд, память 24 ГБ занята едва ли. Qwen3-4B тоже бесплатна и умнее, но на этих четырёх ядрах один ответ часто тянется 10–20 секунд, и кажется, что чат завис. На Space 4B не стоит ставить. Ноутбук по умолчанию ставит 4B, потому что она влезает в бесплатный T4; перед запуском смените базу на `Qwen/Qwen3-1.7B`, если сервер будет бесплатным CPU.

## Шаги

### 1. Секрет Hugging Face

В Colab: слева ключ Secrets, имя `HF_TOKEN`, значение — ваш токен чтения и записи. В Kaggle: Add-ons → Secrets, то же имя. Ноутбук читает только этот секрет. В файл токен не попадает.

### 2. Обучение

Откройте `chiron-server/train_colab.ipynb` на бесплатном T4 (Colab: Runtime → T4 GPU; Kaggle: Accelerator → GPU T4). Прогоните все ячейки. Датасет ноутбук берёт из этого репозитория (`chiron-server/data`).

Если секрет задан, веса уходят сами:

- адаптер: `MaksimSun/chiron-qwen3-lora`
- GGUF Q4_K_M: `MaksimSun/chiron-qwen3-gguf`

Гиперпараметры: QLoRA 4 бита, r=16, alpha=16, dropout=0, длина 1024, batch 1, накопление градиента 8, одна эпоха, lr 2e-4, AdamW 8 бит. Одна эпоха, потому что датасет маленький и вторая легко заучивает каталог. После обучения ноутбук печатает несколько отложенных вопросов и для строк безопасности проверяет слова «врач», «112», «103» или «doctor».

На Kaggle видны две T4. Скрипт использует одну: 4B в неё помещается. Вторая карта простаивает, это нормально.

### 3. Oracle Cloud Always Free (основной сервер)

Нужна бесплатная учётная запись Oracle (её создаёте вы). Образ Ubuntu на Ampere A1: 4 OCPU и 24 ГБ. В некоторых регионах бесплатные ядра уже разобраны — это очередь квоты, не плата. Собирайте образ на самой этой машине, не на ноутбуке: флаг `GGML_NATIVE` привязан к процессору.

```bash
sudo apt update && sudo apt install -y git docker.io
sudo usermod -aG docker "$USER"
# выйти и зайти снова
git clone --depth 1 https://github.com/argunov250-del/bio-age.git
cd bio-age
docker build -t chiron-server chiron-server
docker run -d --name chiron --restart unless-stopped -p 8080:8080 \
  -e CHIRON_KEY='длинная-случайная-строка' \
  -e THREADS=4 \
  -e GGUF_REPO=MaksimSun/chiron-qwen3-gguf \
  chiron-server
```

Контейнер сам скачивает Q4_K_M из `MaksimSun/chiron-qwen3-gguf`, запускает `llama-server` на 127.0.0.1:8000 и прокси на 8080. Прокси требует `Authorization: Bearer`, режет частоту (`CHIRON_RPM`, по умолчанию 30 в минуту с одного адреса) и не пишет тела запросов в журнал.

Снаружи лучше закрыть 8080 и пустить HTTPS через Caddy из пакетов Ubuntu (тоже бесплатно), проксируя на `127.0.0.1:8080`. Порт llama-server в интернет не открывается.

Проверка на машине:

```bash
curl -H "Authorization: Bearer длинная-случайная-строка" \
  http://127.0.0.1:8080/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"chiron","messages":[{"role":"user","content":"Кто ты?"}]}'
```

### 4. Hugging Face Space, бесплатный CPU (запасной)

Space → Docker. В корень Space положите `Dockerfile`, `entrypoint.sh`, `proxy.js`, `limit.js` из `chiron-server/`. Карточка — `chiron-server/space/README.md`. Секрет Space: `CHIRON_KEY`. Переменная `THREADS=2`. Берите GGUF 1.7B: 4B на двух ядрах отвечает слишком долго, и Space ещё засыпает (первый ответ после паузы — десятки секунд сверху).

### 5. Приложение

GitHub → Settings → Secrets → Actions:

- `CHIRON_URL` — публичный адрес прокси, без `/v1` на конце, например `https://chiron.example.org`
- `CHIRON_KEY` — та же строка, что в контейнере

Следующая сборка APK впишет их в приложение. Пока `CHIRON_URL` пуст, чат берёт ответ из каталога.

## Датасет

`npx jest --config chiron-server/jest.config.js` заново пишет `data/train.jsonl` и `data/val.jsonl`. Основа — `answerQuestion` по `lib/coach/qa` (русский и английский, источники, перефразировки). Отказы — готовые сценарии `sensitive` и `cap_diagnose`.

## Необязательно: платная видеокарта и vLLM

Этот раздел не нужен для бесплатного пути. Если позже появится своя GPU, `Dockerfile.vllm` поднимает vLLM и тот же прокси. База `Qwen/Qwen3-4B`, адаптер `MaksimSun/chiron-qwen3-lora`, имя модели в API — `chiron`. На карте класса RTX 4090 короткий ответ 4B часто короче двух секунд (оценка 80–150 ток/с), 8B — около 2–4 секунд (50–100 ток/с). Аренда 24 ГБ на месяц, если не выключать, грубо 220–580 $. Это не часть настройки по умолчанию.
