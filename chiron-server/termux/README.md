# Termux: запасной llama-server на телефоне

Приложению этот путь не нужен. По умолчанию оно само качает `chiron-0.6b-q4_k_m.gguf` и считает его через llama.rn. Termux имеет смысл, только если хочется отдельный процесс `llama-server` и секрет `CHIRON_URL`.

1. В Termux: `pkg install git cmake clang` и соберите `llama-server` из [llama.cpp](https://github.com/ggerganov/llama.cpp), либо поставьте готовый пакет, если он есть в вашем репозитории.
2. Положите `chiron-0.6b-q4_k_m.gguf` в домашний каталог Termux.
3. Запуск только на localhost, четыре потока, без GPU:

```bash
llama-server -m ~/chiron-0.6b-q4_k_m.gguf -c 2048 -t 4 --host 127.0.0.1 --port 8080
```

4. В секрете сборки `CHIRON_URL=http://127.0.0.1:8080`. Ключ не обязателен, если сервер без `--api-key`. Приложение тогда не качает GGUF само, а ходит на этот адрес. Таймаут запроса — 60 секунд, `enable_thinking` выключен.

Снаружи телефон этот порт не публикует. Туннель (Tuna, Cloudflare) нужен только если к модели должен достучаться другой компьютер, и в приложение тогда пишется уже публичный HTTPS-адрес.
